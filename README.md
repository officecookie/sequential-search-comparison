# Последовательный поиск в массивах на C#

Windows Forms приложение на C# для изучения и сравнения алгоритмов последовательного поиска в неупорядоченных и упорядоченных массивах.

## О проекте

Проект разработан в рамках лабораторной работы по теме:

**«Последовательный поиск в упорядоченном массиве. Сравнение алгоритмов последовательного поиска»**

Основная задача проекта — реализовать несколько вариантов последовательного поиска и сравнить их работу на неупорядоченном и упорядоченном массивах.

Программа автоматически создаёт два больших массива:

- `mas1` — неупорядоченный массив;
- `mas2` — упорядоченный массив.

После этого пользователь может выбрать искомое значение и выполнить поиск.

В программе реализованы четыре варианта:

1. Обычный последовательный поиск в неупорядоченном массиве.
2. Последовательный поиск с барьером в неупорядоченном массиве.
3. Последовательный поиск с барьером в упорядоченном массиве.
4. Последовательный поиск в упорядоченном массиве с использованием его упорядоченности и барьера.

Для каждого поиска измеряется время выполнения и определяется индекс найденного элемента.

---

## Возможности

Программа позволяет:

- создавать большие целочисленные массивы;
- автоматически генерировать неупорядоченный массив;
- автоматически генерировать упорядоченный массив;
- выполнять обычный последовательный поиск;
- выполнять последовательный поиск с барьером;
- выполнять поиск в упорядоченном массиве;
- сравнивать время выполнения алгоритмов;
- определять индекс найденного элемента;
- определять отсутствие искомого элемента.

## ⚠️ Требования к оперативной памяти

> **ВНИМАНИЕ:** Для запуска проекта требуется около **4 ГБ оперативной памяти (ОЗУ)**.
>
> Это связано с созданием больших массивов `int[]`, используемых для тестирования алгоритмов последовательного поиска. При недостатке доступной оперативной памяти программа может работать нестабильно или завершиться с ошибкой.
